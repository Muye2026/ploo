# Appearance Spec Template

Write this spec after the user selects a direction. If the user selected an image/video route, use the frozen visual candidate as evidence. If visualization is skipped, derive the spec from the approved textual direction and clearly mark unvisualized details; do not force a render phase.

## Required Sections

1. `Intent`
   - one-paragraph summary of the chosen direction

2. `Primary silhouette`
   - overall body type
   - aspect ratio
   - visual mass distribution
   - symmetry or asymmetry rule

3. `Front-face hierarchy`
   - focal element
   - secondary information areas
   - service or control areas
   - spacing and alignment logic

4. `Side and top read`
   - thickness behavior
   - taper, chamfer, or facet language
   - any controlled overhangs or support forms

5. `Feature language`
   - display window behavior
   - lens or sensor treatment
   - port and button expression
   - seams and split-line intent

6. `CMF guidance`
   - primary materials
   - finish intent
   - contrast strategy
   - any accent color constraints

7. `Forbidden moves`
   - visual decisions that break the selected direction

## Writing Rule

Translate the approved direction and any visual evidence into reusable constraints. Do not write only mood or taste language. Make sure a downstream modeler can infer geometry priorities, and never treat an image as dimensional truth.
